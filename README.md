# Prashant Kalambe Profile

React profile website for `prashantkalambe.github.io`.

## Run locally

```bash
npm install
npm run dev
```

## Publish on GitHub Pages

1. Create a public GitHub repository named `prashantkalambe.github.io`.
2. Push this folder to the repository's `main` branch.
3. In GitHub, open **Settings > Pages** and set the source to **GitHub Actions**.
4. The workflow deploys the site automatically at `https://prashantkalambe.github.io`.
